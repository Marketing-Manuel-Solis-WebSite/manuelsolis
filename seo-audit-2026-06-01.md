- **Option A** — If he is still active at the firm: remove `'edward-s-reisman'` from `DEFUNCT_ATTORNEYS` in `seoRedirects.ts`. His profile page will then be reachable and indexable.
- **Option B** — If he has left the firm: remove his entry from `attorneys[]` in `attorneyData.ts` (lines 445–468). The `DEFUNCT_ATTORNEYS` redirect stays in place to catch inbound links.

### Informational items *(no immediate action required)*

**INFO-01: `proxy.ts` middleware wiring is unclear**

`proxy.ts` at project root contains full Next.js-style middleware logic (cookie + `Accept-Language` detection, uppercase normalization, trailing-slash strip) and exports `export const config { matcher: [...] }` — but the function is exported as `proxy` (not `middleware`) and the file is named `proxy.ts` (not `middleware.ts`). Next.js requires the middleware entry point to be `middleware.ts`. The site works because `app/page.tsx` always falls back to `redirect('/es')`. If browser-language routing is a desired feature, rename `proxy.ts` → `middleware.ts` and rename the export from `proxy` to `middleware`. **Not breaking; do not change unless intentional.**
