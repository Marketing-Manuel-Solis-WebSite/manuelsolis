### ⚠️ WARN — Per-page JSON-LD injected `afterInteractive` on all three pages

Per-page schemas (FAQPage, BreadcrumbList, Person, LegalService) use Next.js `<Script>` component with **no `strategy` prop**, which defaults to `strategy="afterInteractive"`. This means the JSON-LD is **injected into the DOM by JavaScript after hydration** — it is absent from the initial server-rendered HTML.

Contrast with `[lang]/layout.tsx`, which uses raw `<script type="application/ld+json">` inline tags for the Organization/WebSite schemas — those ARE present in initial HTML. ✓

**Consequences of current pattern:**
- Google Webmaster Tools / Rich Results Test may report FAQPage/Person/BreadcrumbList as "not detected"
- Third-party crawlers (Screaming Frog, Ahrefs) miss these schemas
- This is a likely contributing factor to the "Crawled – not indexed" status (thin structured data signal)

**Recommended fix:** Replace `<Script id="..." type="application/ld+json" ...>` with raw `<script type="application/ld+json" dangerouslySetInnerHTML={...} />` in city-service landing `page.tsx` files and `abogados/[slug]/page.tsx`. Pattern to follow: `[lang]/layout.tsx` lines 309–316.
